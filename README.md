# 🛒 Complete E-commerce Functionality

A responsive **E-commerce website** built using **HTML, CSS, and JavaScript**.
This project focuses on practicing real-world JavaScript concepts such as DOM manipulation, CRUD operations, Local Storage, dynamic rendering, search, filtering, and cart management.

## 🌐 Live Demo

**Live Website:**
https://suhailcse2.github.io/complete-ecommerce-functionality/

## 📌 Features

* 🔍 Product search functionality
* 🗂️ Category-based product filtering
* ➕ Add new products
* ✏️ Edit existing product details
* 🗑️ Delete products
* 🛒 Add products to cart
* 🔢 Cart quantity management
* 💰 Automatic cart total calculation
* 💾 Local Storage for products and cart data
* 🔄 Reset stored data
* 📱 Responsive design for different screen sizes
* ⭐ Customer reviews section
* 📩 Contact section
* 🎨 Responsive and user-friendly UI

## 🛍️ Main Functionality

### Product Management

Users can:

* Add new products
* Edit product information
* Delete products
* Search products
* Filter products by category

### Shopping Cart

Users can:

* Add products to the cart
* Set product quantity
* Increase the quantity of an existing cart item
* Remove cart items
* View the total cart price

### Data Persistence

Product and cart data are stored using **Browser Local Storage**, so the data can remain available after refreshing the page.

## 📱 Responsive Design

The website has been designed to work across:

* Desktop
* Tablet
* Mobile devices

Responsive layouts and media queries are used to adapt the interface to different screen sizes.
